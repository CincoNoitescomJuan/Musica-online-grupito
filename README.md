# 🎵 ROLEPLAY MUSIC

> **Cada historia merece su canción.**\
> Una biblioteca musical compartida para dar banda sonora a campañas,
> personajes, escenas y momentos de rol.

ROLEPLAY MUSIC permite reunir canciones, organizarlas por campañas y
escucharlas con un reproductor integrado. También incluye letras
sincronizadas tipo karaoke y salas compartidas para escuchar música en
grupo.

------------------------------------------------------------------------

## ✨ ¿Qué puedes hacer?

-   🎧 **Escuchar canciones** desde el reproductor integrado.
-   📚 **Explorar la biblioteca general** y descubrir las canciones
    compartidas.
-   🗂️ **Organizar música por campañas**, para encontrar fácilmente la
    banda sonora de cada historia.
-   🎤 **Seguir las letras con el modo karaoke**, cuando la canción
    tenga marcas de tiempo.
-   🎶 **Crear tu propia cola de reproducción** y decidir qué canciones
    quieres escuchar a continuación.
-   🖼️ **Añadir portadas, descripciones y letras** para dar personalidad
    a cada tema.
-   👥 **Crear o unirte a salas** para compartir la escucha con otros
    jugadores.
-   ✍️ **Gestionar tus propias canciones**: editar sus datos o
    eliminarlas si ya no quieres compartirlas.

------------------------------------------------------------------------

## 🚀 Cómo empezar

1.  Abre la web de ROLEPLAY MUSIC.
2.  Introduce el nombre con el que quieres aparecer.
3.  Entra en la biblioteca y explora las canciones disponibles.
4.  Pulsa una canción para reproducirla.
5.  Añade temas a tu cola o entra en una campaña para escuchar su
    música.

No necesitas crear una cuenta con correo y contraseña. La web utiliza un
acceso sencillo mediante nombre de jugador y mantiene la sesión en ese
navegador.

> **Consejo:** utiliza siempre el mismo navegador y dispositivo si
> quieres conservar tu sesión.

------------------------------------------------------------------------

## 🎼 La biblioteca

La música está organizada para que puedas encontrar lo que buscas sin
complicaciones.

### Biblioteca general

Aquí puedes consultar todas las canciones compartidas,
independientemente de que pertenezcan a una campaña.

### Campañas

Las canciones pueden estar asociadas a una campaña concreta. Así es más
fácil reunir temas de personajes, lugares, combates o momentos
importantes de una aventura.

### Información de cada canción

Según lo que haya añadido quien la subió, una canción puede incluir:

-   Título y artista.
-   Portada.
-   Campaña asociada.
-   Descripción o contexto.
-   Letra.
-   Marcas de tiempo para el karaoke.

------------------------------------------------------------------------

## ▶️ Reproductor y cola

El reproductor permite escuchar las canciones sin salir de la
biblioteca.

Puedes añadir canciones a tu **cola de reproducción** para preparar una
sesión musical a tu gusto.

-   La cola es personal: cada jugador organiza la suya.
-   Añadir una canción a la cola no la añade automáticamente a las colas
    de los demás.
-   La biblioteca completa no se introduce automáticamente en la cola.
-   El volumen se guarda en el dispositivo o navegador que estés
    utilizando.

En dispositivos móviles también puedes utilizar la vista de reproductor
adaptada a pantallas pequeñas.

------------------------------------------------------------------------

## 🎤 Letras y modo karaoke

Las canciones que tengan letra pueden mostrarla durante la reproducción.

Si además cuentan con marcas de tiempo, el reproductor puede resaltar la
frase que corresponde al momento actual de la canción.

Las marcas se guardan junto a la canción y permiten sincronizar la letra
con el audio. No todas las canciones tienen por qué incluir karaoke.

------------------------------------------------------------------------

## 👥 Salas compartidas

Las salas permiten reunir a varios jugadores para escuchar música de
forma coordinada.

1.  Crea una sala o introduce el código de una sala existente.
2.  Comparte el código con las personas que quieras invitar.
3.  Los demás jugadores podrán unirse.
4.  Una vez dentro, podréis compartir el control de reproducción de la
    sala.

Si una sala está vinculada a una campaña, puede aplicar esa organización
a la música disponible.

------------------------------------------------------------------------

## ⬆️ Subir una canción

¿Quieres añadir música para tu personaje o campaña?

1.  Abre la opción para subir una canción.
2.  Completa el título y el artista.
3.  Selecciona una campaña si corresponde.
4.  Añade una descripción, si quieres explicar cuándo utilizar esa
    canción.
5.  Sube una portada y un archivo de audio.
6.  Añade la letra y las marcas de karaoke si las tienes.
7.  Guarda la canción.

Cuanta más información añadas, más útil será para el resto del grupo.

**Importante:** sube únicamente audio e imágenes que tengas derecho a
compartir. No utilices la plataforma para distribuir material protegido
sin autorización.

------------------------------------------------------------------------

## ✏️ Editar o eliminar tus canciones

Cada jugador puede gestionar las canciones que ha subido.

En tus propias canciones encontrarás la opción **Editar**, desde la que
podrás modificar, entre otras cosas:

-   Título y artista.
-   Campaña.
-   Descripción.
-   Letra y sincronización del karaoke.
-   Portada.
-   Archivo de audio.

Desde ese mismo apartado también puedes **eliminar tu canción** si ya no
quieres que esté disponible.

No puedes editar ni eliminar las canciones de otros jugadores.

> La eliminación es una acción permanente: asegúrate de que quieres
> borrar la canción antes de confirmarla.

------------------------------------------------------------------------

## 🛡️ Administración

La web cuenta con funciones especiales para administradores.

Un administrador puede gestionar el contenido y la comunidad,
incluyendo:

-   Editar o eliminar canciones de cualquier jugador.
-   Gestionar campañas.
-   Gestionar usuarios y sus roles.
-   Administrar las salas.

Estas opciones solo están disponibles para usuarios con permisos de
administración.

------------------------------------------------------------------------

## 🔐 Cuenta, datos y privacidad

ROLEPLAY MUSIC utiliza Supabase para gestionar el acceso, los datos de
la aplicación y los archivos compartidos.

-   Tu sesión se mantiene en el navegador donde has iniciado sesión.
-   Tu nombre de jugador se utiliza para identificarte dentro de la web.
-   Las canciones, sus datos y los archivos asociados se almacenan para
    que puedan compartirse con el grupo.
-   La cola de reproducción es local y personal.

No compartas tu dispositivo con una sesión abierta si no quieres que
otra persona pueda utilizarla.

------------------------------------------------------------------------

## 📱 ¿Se puede usar desde el móvil?

¡Sí! La web está preparada para utilizarse tanto desde ordenador como
desde dispositivos móviles.

Si algo no se actualiza después de una mejora, prueba a recargar la
página. En algunos móviles puede ser necesario cerrar la pestaña y
volver a abrirla o borrar la caché del sitio.

------------------------------------------------------------------------

## ❓ Problemas frecuentes

**No puedo editar una canción.**\
Comprueba que has iniciado sesión con el mismo jugador que la subió.
Solo su propietario y los administradores pueden editarla.

**No aparece el botón de eliminar.**\
Abre la opción **Editar** de una canción que hayas subido tú. El botón
de eliminación está dentro de ese formulario.

**No puedo entrar en una sala.**\
Comprueba que el código sea correcto y que la sala siga disponible.

**No se escucha una canción.**\
Comprueba el volumen del reproductor y del dispositivo. También puede
ocurrir que el archivo de audio ya no esté disponible.

**No veo una canción en una campaña.**\
Puede que esté guardada en la biblioteca general o asociada a otra
campaña.
